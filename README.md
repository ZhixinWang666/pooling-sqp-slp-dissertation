## Repository contents

### `Models/`

This folder contains the AMPL models for the eleven pooling benchmark
problems.

- `mod_dat_document/` contains the AMPL `.mod` and `.dat` files that
  define the model formulations and instance data.
- `nl_document/` contains the corresponding `.nl` files generated by
  AMPL. These files are read by the MATLAB implementations when the
  optimisation problems are solved.

### `starting_points/`

This folder contains one `.mat` file for each of the eleven benchmark
problems. Each file stores the 50 starting points used in the numerical
experiments. For each problem, the same saved starting points are used
by all four implementations.
